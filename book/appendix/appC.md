# 附录 C 论文时间线与导读

> 本表按年份列出书中讨论的论文，方便你按时间顺序补课。标有引用编号的，表示正文引用过，可在附录 D 找到完整条目。

## C.1 怎么用这张表

1. 先看你关心的对象（人体/人脸/人手/动物），找到它的 3–5 个关键节点；
2. 按年份从早到晚读，注意每篇的“前人局限”；
3. 读到不懂的术语，回附录 B 查；
4. 想复现，先看论文的项目页是否提供代码与模型。
