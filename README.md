# 人体参数化技术

> 用几十个参数，描述一个高维的人

从 1995 年的主动形状模型一路讲到 2025 年的 ATLAS / MHR 与扩散模型。人体、人脸、人手、动物四条主线共用同一套数学：平均形状 + 形变基 + 骨架蒙皮。

六册各自独立。一本书内的引用只指向本书，要用到别处概念时会就地补一句解释，所以任意一册都能单独读、单独改。

## 怎么读

- 完全外行、想先有全貌：只读入门册，八章、一个下午。
- 有图形或视觉基础：直接看数学册的 PCA 与骨架蒙皮，再跳到人体册看 SMPL。
- 只做人体：入门册 → 数学册 → 人体册 → 重建册。
- 只做人脸或手：入门册 → 数学册 → 人体册 → 脸手册。
